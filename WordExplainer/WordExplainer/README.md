# Fleench — Developer Setup

1. Open `WordExplainer/WordExplainer` in Android Studio (File > Open). Let Gradle sync.
2. Copy `secrets.properties.example` to `secrets.properties` and fill in the API keys.
3. Plug in your phone (USB debugging on) and press Run, or Build > Build APK(s).
4. Turn on **Fleench** in Accessibility settings.
   - Android 13+: if greyed out, go to Settings > Apps > Fleench > three dots > "Allow restricted settings", then enable.
5. Drag the bubble over any word or sentence to explain it.
