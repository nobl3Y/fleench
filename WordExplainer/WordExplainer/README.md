# Word Explainer

1. Open this folder in Android Studio (File > Open). Let Gradle sync.
2. Plug in your phone (USB debugging on) and press Run, or Build > Build APK(s).
3. Open the app, enter your name and Claude API key, tap Save.
4. Turn on Word Explainer in Accessibility settings.
   - Android 13+: if it is greyed out, go to Settings > Apps > Word Explainer > three dots > "Allow restricted settings", then try again.
5. Drag the circle over words. Drag onto a block and hold to select it whole.
